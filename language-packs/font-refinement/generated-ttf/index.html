Current manual proposal versus the output of PebbleOS FontResourceGenerator, using the repository TTF files and an expanded character list. All 19 missing Czech characters are included. No manual accent editing or Pillow text rasterization is applied to the generated fonts; these images decode the generated PBF pixels.

The generated variant preserves every existing glyph from the current TTF build. Droid Serif may also differ in basic letter shapes from the manual proposal, because that proposal preserves the legacy PBF bodies, whereas the current firmware uses TTF generation. The final ASCII row makes this visible.

The character list used for this preview is a separate copy. Production firmware sources and installed language packs have not been changed. A separate PT2 test firmware now demonstrates this generated variant; see the emulator screenshots above. Rows align the bottom of H; glyphs retain their widths and spacing.
